# Images à fournir

## Visage d'Olivier (fourni ✔)

Déposer **un** de ces fichiers dans `img/` (le jeu prend le premier trouvé) :

1. `img/olivier.webp` (recommandé, plus léger)
2. `img/olivier.png`

Sinon le visage temporaire `img/olivier.svg` est affiché.

`img/olivier-case.webp` est une version recadrée serré sur la tête (256 × 256), tirée de
`olivier.png`, pour la grille. La photo complète sert à la fenêtre « Bravo! ».
Si tu changes la photo, refais aussi ce recadrage (ou supprime-le : le jeu prendra la photo complète).

**Format demandé**

- Carré, **512 × 512 px** (minimum 256 × 256).
- **Fond transparent** : visage détouré (tête et un peu de cheveux, pas d'épaules).
- Le visage remplit ~90 % du carré, centré, de face ou de trois quarts.
- Bien contrasté : il sera affiché très petit (environ 40 px sur une grille 9 × 9).
- Poids visé : moins de 100 Ko.

## Visages supplémentaires (facultatif)

Pour plus de personnalité, on pourra ajouter plus tard :

- `img/olivier-victoire.png` : expression joyeuse (fenêtre « Bravo! »).
- `img/olivier-conflit.png` : expression découragée (Olivier en conflit).

Même format que ci-dessus.

## Autres fichiers

- `img/icone.svg`, `img/icone-192.png`, `img/icone-512.png` : icône d'application
  (grille colorée avec le visage d'Olivier au centre).
- `img/apercu.png` : capture d'écran pour le README et les aperçus de lien.

## Droit à l'image

Olivier Niquet est une personne réelle. Avant de publier, obtenir son accord pour
utiliser son visage dans le jeu (idéalement par écrit, un courriel suffit), et utiliser
une photo dont on a le droit de se servir (prise par soi ou fournie par lui).
